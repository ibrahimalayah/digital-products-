# Brand photos (optional)

Drop these three files here and rebuild; the site picks them up automatically.

| File | Used on | Shape |
| --- | --- | --- |
| `hero.jpg` | Landing page hero | landscape 4:3 |
| `auth.jpg` | Sign-in and sign-up | portrait 3:4 |
| `store.jpg` | Store header and link previews | wide 2:1 |

`.jpg`, `.png` and `.webp` all work. Without them the pages use drawn artwork instead.
